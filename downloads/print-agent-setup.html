Sticker printer set-up

TSC TTP-244 Plus · 27 × 14 mm sticker roll with ribbon · TATGOLD ERP labeling PC (Windows)

1 · Printer on Windows

  1. Load the 27 × 14 mm sticker roll and the ribbon; connect the printer by USB and switch it on.
  2. Install the TSC Windows driver (from the printer's CD or tscprinters.com → Downloads → Driver) and pick the model TSC TTP-244 Plus. Windows then lists a printer with that name — keep the name as it is.
  3. Hold the printer's FEED button once with the roll loaded so it learns the sticker gap (the ERP's Calibrate roll button does the same).

2 · Install the TATGOLD Print Agent (once per PC)

  1. Download tatgold-print-agent.exe  and move it to a folder that stays, for example C:\TatGold\.
  2. Double-click it. Windows SmartScreen may say "Windows protected your PC" because the file is not signed — click More info → Run anyway. If the antivirus asks, allow it.
  3. A page opens at http://127.0.0.1:9123/ showing Running and the printers of this PC. Click Print a test sticker — a framed TATGOLD sticker comes out.
  4. To start it with Windows: open Command Prompt in that folder and run tatgold-print-agent.exe --install (or put a shortcut to it in the Startup folder: Win+R → shell:startup).

The agent only listens on this PC (127.0.0.1) and only answers tatgolderp.com — nothing is opened to the network. Its settings live in tatgold-print-agent.json next to the exe; its log in %LOCALAPPDATA%\TatGold\print-agent.log.

3 · Printing from the ERP

  1. Labeling → Create labels opens the Print stickers screen (also: a label's Print sticker button). It shows every sticker exactly as the printer will draw it.
  2. The first time, the browser may ask whether tatgolderp.com may reach devices on your local network — choose Allow, then click Re-check.
  3. Choose the printer TSC TTP-244 Plus, click Test print, then Print N stickers. Printer, darkness, speed and direction are remembered on this PC.
SettingWhat it does
Darkness 0–15How hot the head prints. Start at 8; go to 10–11 if the print is faint, lower if it smudges.
Speed 1–4Inches per second. 2 is a good balance; 1 is crispest for the small QR.
DirectionIf the sticker comes out upside down, choose Rotated 180°.
Gap between stickersThe blank liner between two stickers (3 mm on the A&D roll). Change it, then Calibrate roll — the printer measures the stickers and stops at the next one.
Left / right · Up / downFine position in printer dots (8 dots = 1 mm). Minus = left / earlier along the roll. Print a Test print (two framed stickers): the frame should sit inside both stickers.
RibbonOn for the ribbon (thermal transfer) rolls; Off only for heat-sensitive (direct thermal) stickers.
Roll handling → Re-align at the start of every jobKeep it on. Before printing, the printer backs the roll up a little and lets its sensor find the start of the sticker, so the print stays on the sticker even after you tear a batch off.
Roll handling → Feed the last sticker to the tear barOn = after a batch the roll moves forward so you can tear it off at the bar. Tear position moves that stop point (minus = earlier).

4 · If something does not work

  • "Print Agent not running" on the print screen — open http://127.0.0.1:9123/ in a new tab. If it does not load, double-click the exe again (a second copy simply opens the page). Check that the antivirus has not quarantined the file.
  • The test sticker prints, ERP stickers do not — the browser blocked local-network access: in the address bar's site settings for tatgolderp.com allow Local network (or Insecure content on older versions), reload and Re-check.
  • Blank sticker — the ribbon is missing or Ribbon is set Off; or the darkness is too low.
  • Text instead of a sticker (commands printed as letters) — the chosen Windows printer is not the TSC printer; pick TSC TTP-244 Plus.
  • Print runs into the next sticker / starts too late — Calibrate roll (Gap 3 mm), keep Re-align at the start of every job on, then Test print: two frames must sit inside two stickers. A remaining constant offset is corrected with Up / down (minus = earlier).
  • Print cut off at the left or right edge — the roll sits off-centre in the printer: push the media guides snug against the roll, then use Left / right.
  • No printer in the list — the TSC driver is not installed or the printer is off; the agent page lists what Windows sees.
  • Browser print (fallback) prints the same stickers through the normal Windows dialog: choose the TSC printer and set its paper to 27 × 14 mm, no margins, 100 % scale.
