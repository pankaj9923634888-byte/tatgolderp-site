Sticker printer set-up

TSC TE244 · 27 × 14 mm sticker roll with ribbon · TATGOLD ERP labeling PC (Windows)

1 · Printer on Windows

  1. Load the 27 × 14 mm sticker roll and the ribbon; connect the printer by USB and switch it on.
  2. Install the TSC Windows driver (from the printer's CD or tscprinters.com → Downloads → Driver) and pick the model TSC TE244. Windows then lists a printer with that name — keep the name as it is.
  3. Load the roll and close the cover. After a new roll run the ERP's Calibrate roll once so the printer measures the stickers and moves the roll to the tear bar — do not press FEED on the printer between batches (the ERP keeps track of the roll position itself; if you did, tick Sure start for the next job).

2 · Install the TATGOLD Print Agent (once per PC)

  1. Download tatgold-print-agent.exe  (any folder — Downloads is fine).
  2. Double-click it once. Windows SmartScreen may say "Windows protected your PC" because the file is not signed — click More info → Run anyway. If the antivirus asks, allow it.
  3. The agent installs itself (in %LOCALAPPDATA%\TatGold\, no administrator rights needed), sets itself to start with Windows and opens its page at http://127.0.0.1:9123/ showing Running, Starts with Windows: Yes and the printers of this PC.
  4. That is all: after every restart the agent starts by itself. If it is ever not running, the ERP's print screen shows a Start agent button (the browser asks once "Open TATGOLD Print Agent?" — tick Always allow and choose Open).
  5. A newer agent is installed the same way: download it and double-click it; it replaces the running one.

The agent only listens on this PC (127.0.0.1) and only answers tatgolderp.com — nothing is opened to the network. Everything it keeps is in %LOCALAPPDATA%\TatGold\: the program, tatgold-print-agent.json (port, printer), sticker-settings.json (the print screen's settings — darkness, gap, left / right, up / down, tear position — so another browser or cleared browser data keeps them), roll-state.json (how far the last job moved the roll) and the log print-agent.log. To stop starting with Windows: tatgold-print-agent.exe --uninstall in that folder.

3 · Printing from the ERP

  1. Labeling → Create labels opens the Print stickers screen (also: a label's Print sticker button). It shows every sticker exactly as the printer will draw it.
  2. The first time, the browser may ask whether tatgolderp.com may reach devices on your local network — choose Allow, then click Re-check.
  3. Choose the printer TSC TE244, click Test print, then Print N stickers. Printer, darkness, speed and direction are remembered on this PC.
SettingWhat it does
Darkness 0–15How hot the head prints. Start at 8; go to 10–11 if the print is faint, lower if it smudges.
Speed 1–4Inches per second. 2 is a good balance; 1 is crispest for the small QR.
DirectionIf the sticker comes out upside down, choose Rotated 180°.
Gap between stickersThe blank liner between two stickers (3 mm on the A&D roll). Change it, then Calibrate roll — the printer measures the stickers and stops at the next one.
Left / right · Up / downFine position in printer dots (8 dots = 1 mm). Minus = left / earlier along the roll. Print a Test print (two framed stickers): the frame should sit inside both stickers.
RibbonOn for the ribbon (thermal transfer) rolls; Off only for heat-sensitive (direct thermal) stickers.
Roll handling → Move the batch out to the tear barKeep it on. After the last sticker the roll moves forward by the Tear position (22 mm by default) so the batch can be torn off at the bar; the next job first backs the roll up by exactly the same distance, so its first sticker starts on its sticker whatever the value is (the printer's own tear-off is not used — on the TE244 it did not bring the roll back to the right place). The stickers after the first one are always placed by the printer's own sensor.
Roll handling → Tear positionWhere the roll stops after a batch. Look at the tear bar after a Test print: it should sit in the small gap after the last sticker. Bar on the last printed sticker → raise by 1 mm; bar on the next blank sticker → lower by 1 mm. Set once per printer.
Roll handling → Sure startFeeds one blank sticker through the printer's sensor before the first real one — one sticker lost per job, but the first sticker can never be misplaced. Tick it once after a new roll, after pressing FEED on the printer or after a paper jam, print, then untick it.

3b · Price tokens on a 58 mm receipt printer

The same agent prints the price token (Price Check → Issue the token, or the token page → Print token) on an ordinary 58 mm thermal receipt printer (ESC/POS — Epson TM, TVS, Xprinter, Rongta …) connected by USB to the PC where the token is issued or opened. Install the printer's own Windows driver (or the "Generic / Text Only" driver) — the agent sends the slip as raw printer commands, so any driver that accepts raw jobs works.

Setting (gear next to Print token)What it does
PrinterThe receipt printer from the agent's list. The sticker printer (TSC) is skipped automatically; pick by hand if the wrong one is chosen.
Copies · Feed lines · CutCopies of the slip; blank lines fed after it so it clears the tear bar; the partial-cut command (printers without a cutter ignore it).
Print automatically when a token is issued hereOn the sales PC: every issued token comes out of the printer at once, no click.
Test printA short slip with a QR that reads PT-0000 — scan it on the Sale Bill's scan box to check the counter scanner.

The slip carries a QR of the token number. At the Sale Bill the cashier points the 2D barcode scanner at it: the scanner types PT-0006 into the scan box and the bill loads the token with its locked discount — the same as typing the number. Without the agent on a PC (or on an iPad) the button prints the on-screen slip through the browser; the PDF for WhatsApp carries the same QR.

4 · If something does not work

  • "Print Agent not running" on the print screen — click Start agent. If nothing happens, download the agent and double-click it once (it installs itself again). Check that the antivirus has not quarantined the file.
  • The test sticker prints, ERP stickers do not — the browser blocked local-network access: in the address bar's site settings for tatgolderp.com allow Local network (or Insecure content on older versions), reload and Re-check.
  • Blank sticker — the ribbon is missing or Ribbon is set Off; or the darkness is too low.
  • Text instead of a sticker (commands printed as letters) — the chosen Windows printer is not the TSC printer; pick TSC TE244.
  • Only the first sticker of a job is misplaced — the roll was moved by hand between two jobs (FEED pressed on the printer, a jam, a new roll). Tick Sure start for one job (or click Feed one) and the next jobs are right again. Never press FEED on the printer between batches. Since agent 1.1 the agent itself remembers how far every job moved the roll — whichever screen or test button printed it — and the first job after the PC starts always begins with one blank sticker, so a restart or the agent's own test no longer misplaces the next sticker.
  • The batch stops short of the tear bar, or a blank sticker comes out after it — adjust Tear position (bar on the last sticker → raise; on the next blank sticker → lower).
  • Every sticker is shifted the same way along the roll — Calibrate roll (Gap 3 mm), then Up / down (minus = earlier).
  • Print cut off at the left or right edge — the roll sits off-centre in the printer: push the media guides snug against the roll, then use Left / right.
  • No printer in the list — the TSC driver is not installed or the printer is off; the agent page lists what Windows sees.
  • Browser print (fallback) prints the same stickers through the normal Windows dialog: choose the TSC printer and set its paper to 27 × 14 mm, no margins, 100 % scale.
